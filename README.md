# Zimní kolo 2027

Interaktivní přehled lokalit pro zimní/jarní cyklistický výlet (silniční kola) s odletem z Prahy nebo Vídně.
Celá stránka je jeden soubor `index.html` bez build kroku.

## Zveřejnění na GitHub Pages

1. Vytvoř na GitHubu nový repozitář, např. `zimni-kolo`.
2. Nahraj do něj `index.html` (Add file → Upload files, nebo `git push`).
3. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, složka `/ (root)` → Save.
4. Za minutu je stránka na `https://<uzivatel>.github.io/zimni-kolo/`.

Data lokalit (klima, lety, ceny, stoupání) jsou v poli `LOC` na začátku skriptu v `index.html`.
